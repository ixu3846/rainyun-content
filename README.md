## 一、雨云是一家什么样的服务商

雨云 2018 年成立，是国内少数强调“自主知识产权”的国产云服务商，公开信息里写着持有工信部颁发的 ISP、IDC、CDN 三类增值电信业务经营许可。产品线铺得很宽：云服务器、游戏云（含面板服和 MCSM 面板）、裸金属物理机、显卡云、虚拟主机、对象存储、雨盾 CDN、云应用。

机房覆盖国内和境外两条腿走路：国内有江苏宿迁、湖北十堰、湖北襄阳、浙江宁波、广东深圳、重庆，境外有中国香港、日本东京、美国洛杉矶。

产品线宽是优点，也是它经常被讨论的原因——便宜的境外小鸡十几元一个月，贵的裸金属和高配显卡云上千元，跨度极大。同一个品牌底下，体验可能完全不是一回事。

## 三、按用途选机房，比按价格选更省事

**只想放个博客、小站，又不想备案**：香港二区和洛杉矶二区是常见选择。香港延迟低、线路好，但多位博主提到它的延迟会周期性波动；洛杉矶二区延迟比香港高约 50ms，走 CMIN2+AS9929 精品线路，稳定性反而更好，代价是洛杉矶二区没开备份功能。

**开 Minecraft 服务器**：别买普通云服务器，直接看游戏云。它用的是高主频 CPU（R9 9950X、i9-14900KF、Ryzen 7950X、Gold 6146、E5-2666v3 等），单核性能对 MC 的 TPS 影响比核心数大得多。固定计费的入门档（E5-2666v3，2核4G，10M，30G 系统盘 + 20G 数据盘）第三方整理价约 65 元/月；京东云 BGP 高防机型的入门级官方页面标价 125 元/月起。

**大带宽下载、图床、网盘**：洛杉矶一区主打 AS4837 国际大带宽，适合吃带宽的业务，代价是国内访问经常跑不满。

**国内业务、怕被攻击**：宿迁走京东云 BGP，带 150G 防御，全国延迟都低，但独立 IP 的价格比同机房服务器本身还贵；十堰和襄阳走三线 BGP，标配 200G 防御，是性价比更均衡的一档。注意国内机房用域名跑 80/443 业务，必须先备案+过白。

## 五、优惠怎么叠：首月5折是起点，不是终点

目前可以确认的优惠结构是这样的：

1. **新用户首月 5 折**：通过专属链接注册、并绑定微信后，系统会发一张首月 5 折的新购券，适用于绝大部分云服务器和游戏云。这是多个第三方评测和官方论坛帖都提到的规则，也是官网购买页会直接标注的“新用户可领首月5折券”。
2. **年付 7 折**：年付本身就有折扣，长期项目基本可以直接按年买。
3. **叠加使用**：有论坛帖提到积分商城可兑换 8 折新购券，与年付 7 折叠加后大约是 5.6 折——也就是说，一些标题里“18元/月”的日本机器，是折扣叠完之后的数字，不是原价。
4. **邀请返利与积分**：账号有消费返利等级，消费后返利比例会提升；邀请新用户也会返券，注册时填写的邀请码决定你的“上级”。这类机制很常见，但要留意它也是雨云在社区被吐槽“营销味重”的原因之一。

## 六、月付价之外，还有几笔钱

- **独立 IP 单卖**：境外机房普通 IP 大约 5 元/月，日本高防 IP 约 30 元/月；国内带防御的独立 IP 价格明显更高，宿迁、十堰一带的报价可以到每月一两百元，和服务器本身的价格是一个量级。
- **流量超额**：限流量机型用完配额后会限速（不同机型 1M～5M 不等），恢复高速要买流量包，价格按机房和档位不同。
- **硬盘扩容**：固态 0.4 元/GB/月，长期大容量存储更建议用对象存储，不是往系统盘里堆。
- **备案成本**：国内机房建站必须备案+过白，这是时间成本，不是钱的问题，但要算进上线计划。

## 七、哪些人我会建议先别买

把话说清楚比硬推更有用。以下几类情况，雨云大概率不是最优解：

- **要 99.9% 以上 SLA、工单分钟级响应**的业务。社区（如 LINUX DO）里关于工单响应慢、放假期间无人处理的反馈不止一条。
- **把香港节点当核心生产环境**的人。多位博主和用户都提到过香港线路延迟波动、甚至被攻击影响连接质量的历史。
- **需要一整套云生态**的团队。对象存储、CDN、数据库、负载均衡这类配套，雨云的完整度跟头部大厂不是一个量级，官方文档也不算丰富。
- **不接受超售逻辑**的用户。雨云在低价区间被质疑超开超卖，属于国内中小 IDC 的普遍现象，但确实有人因此直接避雷。
- **只要一台稳定机器、且预算充足**的个人用户。腾讯云、阿里云的活动年付价有时候更省心。

反过来说，预算敏感、有一定 Linux 基础、能接受自己查文档解决问题、主要用于建站 / 开服 / 挂机 / 测试的人，才是雨云价格结构真正服务的人群。

## 八、常见问题

**雨云需要备案吗？**
国内机房（宿迁、十堰、襄阳、宁波、深圳、重庆）用域名跑 80/443 需要备案+过白；香港、日本、洛杉矶机房免备案。

**NAT 和独立 IP 差在哪？**
NAT 是共享 IP，端口数量有限（不同产品在 5～10 个之间），价格便宜，适合内网穿透、学习、开服，不能用来建站；独立 IP 独享地址，带防御的机房还能独享防御，但要单独付费。湖北十堰等机型默认是 NAT，建站必须加购独立 IP。

**能退款吗？**
公开规则是 7 天内无理由退款，每个账号限 3 次；云服务器和游戏云另可 1 元试用 1 天。

**免费游戏云靠谱吗？**
作为和朋友联机的入门路径是够用的，7 天有效期靠签到积分续期。它本质是引流产品，库存和带宽都不是主力资源，别拿它当长期生产环境。

**和头部大厂比，优势真的只是便宜吗？**
不完全是。续费价格稳定是不少人选择它的实际原因——首年促销便宜、次年翻倍是很多大厂轻量服务器的常态，雨云的年付 7 折是长期规则。代价是生态、文档、售后响应这些软实力要弱一档。
